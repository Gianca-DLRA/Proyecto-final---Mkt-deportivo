# Proyecto final: Marketing deportivo
## Descripción
Este proyecto tiene como objetivo una exploración de datos de Stats Bomb y una propuesta de estrategia dentro del contexto de aprovechamiento de tiros de esquina.
Este proyecto se basa en la problemática del Hackathon de ISAC 2025.

## Nota de los datos
Los datos utilizados para este proyecto exceden el límite permitido de GitHub de tamaño. Por lo tanto no se incluyen en el repositorio.
